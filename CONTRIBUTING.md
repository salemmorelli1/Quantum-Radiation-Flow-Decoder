# Contributing

1. Create a focused branch.
2. Preserve the separation between quantum and classical entropy quantities.
3. Add tests for every mathematical or numerical change.
4. Run `pytest`, `ruff check .`, and the repository validator.
5. Document seeds, configurations, and changed estimands.

Do not label classical differential entropy as von Neumann entropy, or a toy
inverse map as a physical Hayden-Preskill decoder, without an explicit theorem
and measurement model supporting that interpretation.
