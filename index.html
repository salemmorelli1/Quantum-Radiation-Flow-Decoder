What this browser model does—and does not—claim.

It does: expose a finite Page benchmark, animate an analytic telemetry surrogate, distinguish entropy definitions, and demonstrate how paired inverse coordinates can be scored.
It does not: run the trained PyTorch model in your browser, identify von Neumann entropy from one classical measurement basis, or prove unitary black-hole evaporation.
